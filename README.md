# CodeAlpha_Hangman_Game# 🎮 Word Hunter - Hangman Game

A Python-based Hangman game developed as part of my CodeAlpha
Python Programming Internship.

## Features

- Category-based word selection
- Random word generation
- Hint system
- Repeated guess detection
- Score calculation
- Limited wrong attempts

## Technologies Used

- Python
- Random module
- Loops
- Conditional statements
- Sets
- Dictionaries

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the terminal in the project folder.
4. Run:

python hangman.py
